FuPan 复盘

memorize by reviewing

一个单文件部署的间隔重复记忆应用：把你的 Markdown 笔记切成卡片， 用 FSRS 遗忘曲线安排复习，配一个会质询、联网核实、并提案改进卡片的 AI 考官。 以下是当前已实现的功能，每张卡都可以点击翻面——就像复习时那样。

为什么间隔重复
比集中背诵记得牢？

遗忘主要发生在回忆刚建立时；在快要忘记的临界点提取记忆，每次成功回忆都会拉长下一次遗忘的间隔——这就是 FuPan 用 FSRS 调度每张卡的原因。

👆 点击卡片翻面——复习时的动作，这里也一样

  • 知识库与卡片多库管理 · 溯源到原文
  • 调度算法FSRS（可调目标保持率）
  • 部署形态Go 单二进制 · SQLite · 零外部依赖
  • AI 服务商DeepSeek / 智谱 / OpenAI / Ollama 混搭
  • 界面内置静态前端 · 纸质主题

Agent 问答式复习

把卡片丢给一个AI 考官：它会追问你的薄弱点，联网核实你的答案，想改卡片时先提案、你点头才算数。三条红线：判级你确认、修改你批准、额度你可控。

技术底座

为上线设计

跑起来只有一个文件；数据就在你手里。

Go 单二进制前端经 go:embed 内嵌，./fupan 即起服务，无 Docker 依赖
SQLite 存储卡片、调度、日志、提案单库管理，备份即拷文件
OpenAI 兼容协议对话与嵌入独立配置，任意兼容服务商可接
HITL 设计出卡、判级、改卡三处 AI 动作全部人工确认
BYOK 计费AI 与搜索均用用户自己的 Key，部署方零边际成本
幂等迁移schema_migrations 记录表，旧库升级无感
