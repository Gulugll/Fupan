## 2. 数据库 Schema（migrations/0001_init.sql）

```sql
libraries(id TEXT PK, name TEXT NOT NULL UNIQUE, description TEXT, created_at TEXT)
documents(id TEXT PK, library_id TEXT NOT NULL REFERENCES libraries, title TEXT, format TEXT, created_at TEXT)
chunks(id TEXT PK, doc_id TEXT NOT NULL REFERENCES documents,
       parent_id TEXT REFERENCES chunks,            -- 子块指向父块；父块为 NULL
       kind TEXT NOT NULL,                           -- 'parent' | 'child'
       title_path TEXT, seq INTEGER,                 -- 标题路径 / 块序号
       content TEXT NOT NULL, char_start INTEGER, char_end INTEGER,
       author TEXT NOT NULL DEFAULT 'user',          -- user/agent
       version INTEGER NOT NULL DEFAULT 1, created_at TEXT)
       -- 硬约束：content 永不 UPDATE，修订一律 INSERT 新行（version+1）
cards(id TEXT PK, library_id TEXT NOT NULL, front TEXT NOT NULL, back TEXT NOT NULL,
      type TEXT NOT NULL DEFAULT 'qa',
      source_chunk_id TEXT NOT NULL REFERENCES chunks,   -- 溯源必填，NOT NULL
      source_version INTEGER NOT NULL, status TEXT NOT NULL DEFAULT 'active', created_at TEXT)
schedules(card_id TEXT PK REFERENCES cards, state TEXT NOT NULL DEFAULT 'new',
      due TEXT NOT NULL, stability REAL, difficulty REAL,
      elapsed_days INTEGER, scheduled_days INTEGER, reps INTEGER DEFAULT 0, lapses INTEGER DEFAULT 0,
      introduced_date TEXT)                          -- 当日新卡计数依据
review_logs(id TEXT PK, card_id TEXT NOT NULL REFERENCES cards,
      rating INTEGER NOT NULL CHECK(rating BETWEEN 1 AND 4), reviewed_at TEXT NOT NULL)
settings(key TEXT PK, value TEXT)                    -- llm.base_url / llm.api_key / llm.model / embed.model / fsrs.retention / review.daily_new_limit
```

ID 全部用 UUID（crypto/rand）。事务：导入（doc+chunks）、卡片提交、复习（schedule+log）均在单事务内。

## 3. API 一览（/api 前缀，JSON）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET/POST | /libraries | 列表 / 建库 |
| DELETE | /libraries/:id | 删库（级联清向量） |
| GET | /libraries/:id/documents | 文档列表 |
| POST | /libraries/:id/documents | 上传 MD/TXT（multipart），同步完成切片+向量化 |
| GET | /documents/:id | 文档详情 + chunk 树（含父块） |
| DELETE | /documents/:id | 删文档 + 按 doc_id 清 Milvus |
| POST | /cardgen/preview | {chunk_ids} → 返回草稿卡（**不落库**） |
| POST | /cardgen/commit | {cards:[{front,back,source_chunk_id}], library_id} → 落库 |
| GET | /libraries/:id/review/queue | 今日复习队列（到期优先+新卡混排，新卡≤20） |
| POST | /cards/:id/review | {rating:1..4} → FSRS 计算并落库 |
| GET | /cards/:id/source | 卡片溯源：文档名 + 标题路径 + 父块全文 + 子块定位 |
| GET/PUT | /settings | LLM Key 等配置读写 |
| GET | /health | 健康检查 |

Milvus 检索在 V0.5 仅做「写入路径 + DELETE /documents 清理」+ 一个最小调试端点 `GET /api/search?library_id=&q=`（用于验证向量链路通），完整 RAG 留 V1.0。
